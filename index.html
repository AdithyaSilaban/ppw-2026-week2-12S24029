PROFIL

MENATA LOGIKA, MEMBANGUN SOLUSI.

Saya Adithya Philip Jona Putra Silaban, mahasiswa Sistem Informasi di Institut Teknologi Del dengan minat kuat pada analisis sistem, UI/UX, dan pemrograman berorientasi objek. Saya terbiasa membedah proses yang berantakan lalu merancangnya ulang jadi solusi yang berorientasi pengguna.

Dari menyusun System Requirement Specification dan use case, melakukan evaluasi heuristik pada desain antarmuka, hingga menulis logika Java untuk pemrosesan data transkrip akademik. Saya suka pekerjaan yang menuntut saya menerjemahkan kebutuhan bisnis jadi sesuatu yang benar-benar berfungsi.
